# 🐺 The Witcher 3 — Save Deleter (Менеджер очистки сохранений)

Удобная графическая утилита на Python / Tkinter для быстрого просмотра, пакетного выбора и безопасного удаления сохранений игры **The Witcher 3: Wild Hunt** («Ведьмак 3: Дикая Охота»).

---

## 📌 Зачем это нужно?

В процессе прохождения «Ведьмака 3» игра создает огромное количество промежуточных файлов: контрольные точки, автосохранения и ручные слоты. Со временем их количество превышает сотни (и даже тысячи), занимая **гигабайты на диске**.

Стандартный интерфейс игры позволяет удалять сохранения только по одному с длительной анимацией подтверждения. **The Witcher 3 Save Deleter** решает эту проблему в несколько кликов.

---

## ✨ Ключевые возможности

- 🖼️ **Крупные качественные превью (160×90)**.
- 🖱️ **Продвинутое выделение мышью**:
  - Клик в **любую область строки** переключает выбор.
  - **Drag-selection**: зажмите левую кнопку мыши и проведите курсор по списку, чтобы мгновенно выделить нужный блок сохранений.
  - Поддержка горячих клавиш: `Shift + Клик` (выделение диапазона), `Ctrl + Клик` (выборочное переключение).
- 🎯 **Быстрый выбор в один клик**:
  - Кнопка *«Автосейвы и Чекпоинты»* — выделяет все временные сохранения, оставляя важные ручные сейвы нетронутыми.
  - Кнопки *«Выбрать все»*, *«Снять выбор»*, *«Инвертировать выбор»*.
- 📊 **Подробная статистика**: расчет точного веса каждого сохранения (`.sav` + `.png`) и общий подсчет освобождаемого места (МБ / ГБ).
- 🔍 **Автопоиск папки**: автоматическое обнаружение стандартных директорий игры (`Documents\The Witcher 3\gamesaves` и путей через OneDrive).

## 🚀 Быстрый запуск на Windows (в 1 клик)

Для пользователей Windows предусмотрен файл пакетного запуска **`run.bat`**:

1. Скачайте репозиторий (кнопка **Code** → **Download ZIP** или `git clone`).
2. Распакуйте архив в удобную папку.
3. Дважды щелкните по файлу **`run.bat`**.

> Скрипт `run.bat` автоматически проверит наличие Python, создаст изолированное окружение (`venv`), установит необходимые библиотеки (`Pillow`, `send2trash`) и запустит программу.

## 🛠️ Ручная установка и запуск

Если вы хотите запустить проект вручную через терминал:

### Требования
- Python 3.9 или выше.
- Операционная система: Windows 10 / 11 (поддерживаются также Linux и macOS).

### Шаги установки:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ras-pl/The-Witcher-3-save-deleter.git
   cd The-Witcher-3-save-deleter
   ```

2. **Создайте и активируйте виртуальное окружение (рекомендуется):**
   ```bash
   python -m venv venv
   # На Windows:
   venv\Scripts\activate
   # На Linux / macOS:
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите программу:**
   ```bash
   python save_deleter.py
   # или
   python main.py
   ```

## ⌨️ Управление и горячие клавиши

| Действие | Описание |
|---|---|
| **ЛКМ по строке** | Выбрать / снять выбор конкретного сохранения |
| **Зажать ЛКМ и тянуть** | Массовое выделение подряд идущих сохранений |
| **Shift + ЛКМ** | Выделить диапазон от предыдущего сохранения до текущего |
| **Ctrl + ЛКМ** | Добавить / убрать конкретное сохранение из выборки |
| **Колесико мыши / Стрелки ↑ ↓** | Плавная прокрутка списка сохранений |
| **Page Up / Page Down** | Прокрутка страницы целиком |
| **Home / End** | Переход в самый верх или самый низ списка |

## ⚠️ Безопасность ваших сохранений

- Программа удаляет только пары файлов: само сохранение (`.sav`) и прикрепленный скриншот (`.png`).
- Всегда рекомендуется делать резервную копию папки `gamesaves` перед глобальной очисткой.
